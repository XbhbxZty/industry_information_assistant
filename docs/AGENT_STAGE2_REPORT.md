# 第二阶段：可阅读、可引用、可复算的自主调查

## 目标与边界

第一阶段主要修复规则依赖、评估路径与交付状态。本阶段是功能性改造：让 AI 自主选择材料、继续阅读、组合证据、计算并修订分析，而不仅在固定工程结果上生成文字。

不把“AI 参与更多”理解成取消证据闸门。工具计算正确不等于主体、口径、期间或因果关系成立；材料中存在一句话不等于外部真实性已经核验。确定性评级、授信建议和人工复核边界继续保留。未新增自动审批或放款动作。

## 已实现

1. **授权材料目录与跨片段阅读**：直接列出本次选择且归当前用户所有的材料，不必先在语义检索前几名命中。展示索引状态、片段数、未读/部分已读状态；支持 `read_next` 跨片段及长片段分页。只有实际读到的范围计入覆盖，失败不写成“无资料”。
2. **阅读与字段抽取分离**：`read_source` 首先交付原文；AI 按需使用 `extract_evidence`。抽取失败不丢失阅读成果，字段核实仍走原有验证链。合并/母公司口径由服务端标注，分页时正确重定位口径标记。
3. **多引文分析**：一条发现可组合最多六条精确原文引文，支持跨材料比较与反证。保留旧单引文接口。已引用的正文即使位于摘要截断范围以外，也会进入 Critic 上下文及报告附录。
4. **计算底稿**：新增带来源与原文的变量、四则公式、结果、单位/期间/主体及限制说明。安全表达式白名单与 Decimal 计算避免执行任意代码；每个数值必须对应真实已读引文。计算底稿可关联调查发现，但不直接改变字段核实或规则评分。
5. **有效进展与收束**：近重复措辞不算新发现；重复计算和重复读取不算新进展。连续翻页由工具判断覆盖，避免循环层误拦。停滞恢复阶段仍允许读取剩余材料、形成引文分析与计算，不强制把未读材料当不存在。
6. **前端调查工作台**：显示材料覆盖、多条依据、计算公式、变量原文及限制；兼容旧事件和旧检查点。调查预算改为累计最多 24 个行动、420 秒，不是无限自主执行。
7. **真实 HTTP 验收工具**：新建普通测试账号和知识库，经鉴权、上传、索引、研究流及检查点接口执行。密码与令牌仅在内存中；归档脱敏；链路通过与内容质量判定分开。
