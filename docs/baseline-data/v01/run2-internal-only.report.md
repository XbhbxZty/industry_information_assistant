## 尽调结论摘要

本报告对东莞市泰锐精密传动件有限公司（以下简称“泰锐精密”或“该公司”）申请2000万元应收账款保理业务进行了贷前尽职调查。公司成立于2015年，存续超过11年，主营业务与保理基础交易匹配。核心风险集中于财务层面：公司呈现“增收不增利”特征，净利润从2023年的1820万元下滑至2025年的940万元；资产负债率快速攀升，从55.8%升至72.9%；经营性现金流急剧恶化，从2023年净流入1240万元转为2025年净流出1580万元；应收账款规模激增，从2023年的8900万元增至2025年的19850万元，是本次授信的核心风险点。此外，公司存在被执行记录（标的342万元）及未决诉讼，参保人数持续下降，均构成风险叠加。

**信息缺口**：本次尽调存在大量关键信息缺失，包括：1）公司最终实际控制人身份；2）应收账款账龄结构及主要债务人信息；3）前五大客户及销售占比；4）主营业务产品明细及生产产能；5）关联方清单、关联交易及对外担保情况；6）股东背景、股权质押及历史变更情况；7）除已披露诉讼外的其他合规风险（如环保、税务处罚等）；8）参保人数与经营规模的匹配度。这些信息缺口严重影响对借款人真实偿债能力及应收账款质量的评估。
