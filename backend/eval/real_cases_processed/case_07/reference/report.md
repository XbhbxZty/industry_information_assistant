## 五、参考报告

### 5.1 经证据验证的事实

金科地产集团股份有限公司统一社会信用代码为 `91500000202893468X`，证券代码 `000656`。法院管理人公告及最终重整计划均记载其成立于1994年3月29日，而2024年度报告摘要的业务介绍写为“公司成立于1998年”，因此成立年份应保留为 `conflicting`，不得为了表格整洁自行覆盖。〔C001-C004；S01/S03/S05〕

重庆金科房地产开发有限公司统一社会信用代码为 `91500000203026104B`，是另一个独立法律主体。金科股份重整计划显示，截至2024年4月30日上市主体持有38家一级子公司；重庆金科计划又显示其持有74家一级子公司。两份重整计划还分别设计了不同的资产保留、服务信托和债权清偿机制。〔C007、C032-C034〕

2024年4月22日，重庆五中院裁定受理金科股份及重庆金科重整。2025年5月10日、11日，两家公司分别收到法院裁定，重整计划获得批准并终止重整程序。因此截至2025年5月31日，它们不是“尚在等待是否重整”，而是已经进入重整计划执行与监督阶段；金科股份计划监督期限为八年。〔C008-C010〕

金科股份财务状况在截止日前仍极弱。2022、2023、2024年归母净利润分别约为 **-213.92亿元、-87.32亿元、-319.70亿元**；2024年末归属于上市公司股东的净资产为 **-286.83亿元**。2025年一季度又亏损约16.17亿元，2025年3月31日归母权益进一步降至 **-303.00亿元**。〔C013-C017、C022-C024〕

截至2024年末，有息负债本金698.29亿元，其中逾期本金494.48亿元。天健同时指出公司存在金融机构借款、债券兑付、施工方工程款逾期，多起诉讼仲裁以及部分资产和银行账户被冻结或强制执行。〔C018-C019〕

2024年度审计报告为**保留意见**。准确表述应为：审计师认为持续经营假设本身仍可用于报表编制，但公司存在可能对持续经营能力产生重大疑虑的重大不确定性，对相关不确定性的披露不充分，且审计师无法取得充分证据判断部分事项，因此发表保留意见；保留事项并非直接否定报告期所有财务数字。〔C020-C021〕

2024年度，公司因部分非并表公司或已经进入破产程序的原子公司融资连带责任担保，计提约 **13.29亿元财务担保信用减值损失**。该数字反映担保风险损失估计，并不能直接当作公司全部对外担保余额。〔C029〕

金科股份重整计划中，普通债权总额约755.34亿元、涉及6019家（户）债权人。以100万元普通债权为示例，计划预计首次分配综合清偿率约22.36%；1000万元、1亿元、5亿元示例对应的首次分配综合清偿率更低。重庆金科自身100万元普通债权示例预计首次分配综合清偿率仅11.64%。〔C030-C034〕

两个比例不能解释为“所有金科体系债权统一打折比例”。它们说明的是：**债务主体不同，重整财产、债权池和清偿方案也不同。**

### 5.2 从事实推导出的分析

第一，**不能将项目公司的商业品牌、控股关系或“金科体系”身份转换为上市公司的付款义务。**

破产法及金科股份正式重整计划均保留债权人对真正的主债务人、保证人及其他承担清偿责任主体的权利，但前提是这些主体原本就存在合同、保证、债务加入、票据或其他法定责任。〔C035〕

因此，假设供应商合同签约人为“A市金科XX置业有限公司”，仅凭：

`项目公司 → 重庆金科 → 金科股份`

这样的股权链，不能写成：

`应收账款债务人 = 金科股份`

必须找到独立的责任连接点，例如金科股份是合同共同债务人、保证人、债务加入人、票据责任人，或者已有生效裁判明确其承担责任。

公司披露的执行案件反向验证了这一点：部分建设工程纠纷仅由具体项目公司承担诉讼/执行责任，而另一些票据、借贷或建设工程案件中金科股份被明确列为责任主体。〔C037〕

第二，**旧应收账款不能按票面金额直接做上市主体信用。**

若拟保理债权确属重整受理前形成的金科股份债务，就需要继续核实其是否已经申报、管理人是否确认、债权分类、是否存在担保财产以及按重整计划能够取得什么偿债资源。金科股份100万元普通债权22.36%的计划示例本身已经说明普通债权的经济价值与票面值存在重大差异。〔C030-C031〕

第三，**“重整期间新增融资”在截止日需要重新定义。**

2025年5月10日、11日法院已批准计划并终止重整程序。按照破产法，法院批准后由债务人执行计划、管理人监督执行。故5月31日新增融资属于**重整计划执行阶段融资**，不能机械套用“重整期间融资”标签，更不能仅因发生在重整后就自动认定为共益债务、超级优先债权或享有法定优先受偿权。

如果融资机构的准入逻辑依赖“新增融资优先于普通债权”，必须取得具体法律结构、计划依据、管理人意见、公司授权和担保登记，而不能只看融资发生时间。

第四，**重整计划获批是积极变化，但不足以逆转截止日信用质量。**

积极因素包括：法院已经批准两份计划，司法程序从是否能够重整的不确定阶段转入执行阶段；计划引入26.28亿元重整投资并安排流动性支持。另一方面，截至计划文本，能够直接验证的是第一期7.88亿元保证金已足额支付，其余款项存在后续付款节点；已访问的截止日前资料不足以确认截至5月31日26.28亿元已全额到账。〔C039-C040〕

与此同时，公司仍有负303亿元级归母权益、近494亿元逾期有息债务基数、持续经营重大不确定性和巨额历史诉讼。因此不能把“法院批准计划”直接转写成“信用恢复正常”。

### 5.3 未经验证的假设

以下说法均不得进入事实层：

- “金科项目公司欠款最终都会由上市公司兜底”；
- “重整后的所有新融资都是共益债”；
- “供应商拥有发票，所以债权不存在争议”；
- “重整计划批准后旧债已经全部化解”；
- “26.28亿元投资款截至2025年5月31日已经全部到账”；
- “项目公司与金科股份存在内部资金归集，因此可以穿透追偿”；
- “某一工程债权不存在抵销、反索赔、质量扣款或重复保理”。

这些均缺少交易级证据。

### 5.4 数据缺口

对具体保理交易，最低限度仍缺：

- 原始施工/采购合同；
- 补充协议；
- 项目公司完整主体代码；
- 订单和发票；
- 工程进度/验收资料；
- 结算单；
- 对账单；
- 债务人确权函；
- 是否存在质量扣款/索赔/抵销；
- 金科股份保证或债务加入文件；
- 保证授权文件；
- 债权申报与管理人确认资料；
- 既往转让/保理/质押登记；
- 回款账户控制安排。

此外，本轮中国执行信息公开网访问超时、国家企业信用信息公示系统返回403，因此没有能力将“失信/限制消费/经营异常/工商行政处罚”标成 `no_record_found`。

### 5.5 截止日之后的后验结果

**以下信息严格不参与2025-05-31风险等级判断。**

2025年12月，公司公告称金科股份及重庆金科重整计划已经执行完毕，并披露相关偿债资源、服务信托及新增2.5亿元借款等执行情况。〔C041〕

2026年7月2日起，深交所撤销金科股份退市风险警示及其他风险警示，证券简称从“*ST金科”恢复为“金科股份”。公告同时披露2025年度审计为无保留意见、归母净资产恢复为正，但扣非归母净利润仍为巨额负值。〔C042〕

这些结果可以用于测试 Agent 是否发生“未来信息泄漏”，但不能用于降低2025年5月31日的参考风险等级。
