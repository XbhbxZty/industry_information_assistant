## 五、参考报告

### 5.1 经证据验证的事实

**主体已经锁定。** 2020年报和2021年报均将康美药业股份有限公司的统一社会信用代码记载为 `91445200231131526C`，上市代码为600518。因此候选代码可以升级为 verified，而不是继续作为数据库候选值使用。（C001、C002、C003；SRC001、SRC002）

**历史财务报表存在监管认定的系统性失真。** 中国证监会认定康美2016年报、2017年报、2018半年报和2018年报存在虚假记载。例如，2017年报被认定虚增货币资金29,944,309,821.45元；2016—2018年还存在未按规定披露的关联方非经营性资金占用。（C110、C190、C191；SRC010）

**不能根据历史“标准无保留意见”恢复对财务数据的信任。** 原审计机构对2016、2017年度曾出具标准无保留意见，对2018年度出具保留意见，但证监会后来认定其2016—2018年度审计报告存在虚假记载，并指出包括银行函证、风险评估等审计程序存在问题。（C105、C192；SRC011）

**2020年度本身存在两个重要财务版本。** 2021-04-28披露的2020年报载明总资产约362.13亿元、归母净利润约-277.36亿元、归母净资产约-71.86亿元，并由立信出具无法表示意见。（C141、C143、C144、C147；SRC002）

2022-04-29，公司又对2020年度进行追溯重述，调减资产2,886,849,021.28元、调增负债463,612,436.23元、调减归母权益3,350,287,486.39元；重述后2020年总资产约333.26亿元、总负债约437.36亿元、归母净资产约-105.36亿元。（C151、C153、C154；SRC008、SRC009）

正确的数据表示方式应为：

```text
2020/V2021-original = 362.13亿元
2020/V2022-restated = 333.26亿元
```

两者都是历史上真实存在的公开披露版本，后者不能覆盖前者。

**林下参减值归属期间发生过版本变化。** 2021年10月公开材料表示，由于当时无法确定具体减值期间，相关约33.31亿元差额先调整到2021年期初；2022年4月取得进一步材料后，公司认定最早应追溯至2020年度。（C149、C150；SRC007、SRC008）

**2021年账面盈利不能直接理解为主营经营恢复。** 2021年归母净利润约79.18亿元，但扣除非经常性损益后的归母净利润约-79.68亿元，经营活动现金流净额仅约2.14亿元。（C161—C163；SRC001）

**截至当时公司刚完成司法重整。** 年报披露，揭阳中院于2021-11-26裁定批准重整计划并终止重整程序，2021-12-29裁定确认重整计划执行完毕；重整后神农氏成为控股股东，公司披露无实际控制人。（C006、C007、C171；SRC001）

**历史关联方资金占用规模重大。** 证监会认定2016—2018年公司累计向实控人及关联方提供非经营性资金约116.19亿元；2020年末相关关联方资金占用余额约84.81亿元。2021年报披露前述历史占用已经清偿。（C148、C170、C191；SRC001、SRC002、SRC010）

需严格区分主体：普宁市康淳药业有限公司、普宁康都药业有限公司等是相关关联方，不能把这些关联企业自身全部法律或经营风险自动归入康美药业；与康美直接相关的是其资金占用及相应应收、清偿问题。

**证券虚假陈述已经产生生效司法赔偿责任。** 最高人民法院公布的典型案件显示，广州中院于2021-11-12就康美药业特别代表人诉讼作出判决，专业机构测算扣除市场系统风险等因素后的投资者损失约24.59亿元，相关判决已发生法律效力。（C193、C194；SRC012）

### 5.2 从事实推导出的分析

第一，**财务数据可靠性风险在2022-05-31仍属于核心风险，而不是纯历史事件。** 原因不仅是2016—2018造假，还包括直到2022-04-29公司仍在对2020报表进行数十亿元量级的追溯调整。因此，对未经交易级证据验证的资产、存货、应收及利润数字应提高折扣程度。（依据C150—C156、C190、C192）

第二，**2021年的79.18亿元归母净利润不足以构成经营修复证据。** 同期扣非净利润约-79.68亿元，OCF仅约2.14亿元，说明当年盈利高度受到非经常性事项、重整等因素影响，主营经营造血能力仍弱。（依据C161—C163）

第三，**重整显著改善资产负债表，但“资产负债表修复”与“经营信用修复”不能等价。** 2020重述后负债约437.36亿元，而2021年末负债约60.86亿元；但同期扣非仍巨亏，2022Q1归母净利润继续为负。（依据C153、C165、C162、C181）

第四，对于供应链金融，**上市主体信用不能替代特定应收账款真实性和可转让性的验证。** 2021年末存在约13.57亿元应收账款，并不能证明具体融资申请对应债权真实、未转让、未质押或不存在重复融资。（依据C166、C200、C201）

### 5.3 未经验证的假设

以下内容不得写入事实层：

- “重整以后银行已经恢复正常授信”——未验证。
- “历史资金占用清偿后资金均为高质量现金”——未完成独立穿透验证。
- “康美不存在新增关联方资金占用”——只能表述为2021年报披露没有新增及原占用已清偿。
- “不存在其他被执行、失信或限制消费事项”——本次没有完成可证明全量覆盖的历史司法执行查询。
- “某笔应收账款未质押、未转让、未保理”——未验证。
- “2021正利润代表主营恢复”——与扣非及现金流数据不一致。

### 5.4 数据缺口

最影响实际授信结论的并非公开年报，而是以下私域或交易级证据：

银行流水、纳税申报及完税数据、企业征信、重整后各银行实际授信和留债余额、债务偿付台账、保证/抵质押清单、中登网针对具体债权的登记结果、应收账款客户明细及账龄、客户函证、合同、发票、物流/验收材料、对账与确权、历史回款、关联方清偿资金来源及相关资产估值底稿。

因此：

```text
credit_amount = null
```

### 5.5 截止日之后的后验结果

本案例的参考风险判断**未使用2022-05-31之后的信息**。

本轮没有系统扩展抓取截止日后的经营、退市风险变化、后续监管处分、后续债券清偿和经营恢复情况，因此：

```json
"post_cutoff_outcomes": []
```

该字段为空表示“未纳入本案例包”，不表示“截止日后没有发生事件”。
